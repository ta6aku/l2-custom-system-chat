# l2-custom-system-chat
dll collector and ahk.v2 overlay for Lineage 2 C1-C2 client that realize customizable system chat window  


## Инструкция
1. Поместите папку с файлами в `Patches`:
   ```text
   Lineage2/
   └── Patches/
       └── SystemChat/
           ├── SystemChat.ahk
           ├── SystemChat_Configurator.ahk
           ├── Starter.ahk
           ├── SystemMsgExt.dll
           ├── SystemChat_Config.ini
           ├── lib/
           ├── resources/
           └── ....
   ```
2. Запустите **SystemChat_Configurator.ahk**, чтобы настроить параметры окна чата и фильтруемые сообщения  

3. Запустите игру, запустите **Starter.ahk**    



## Принцип работы
DLL-инжектор при загрузке в память процесса игры создает основной поток, который находит базовые адреса `network.dll` и `nwindow.dll` и устанавливает аппаратные брейкпоинты (DR0 и DR1) на главном потоке по фиксированным смещениям.  
Перехват событий через VEH. Из функции network.dll — ID сообщения. Из функции nwindow.dll — текст уже сформированной строки.  
Отправка сообщения осуществляется через WM_COPYDATA в окно AHK в рамках отдельного фонового потока с таймаутом на отправку и ограничением размера очереди.  

AHKv2 скрипт отображает поверх Lineage 2 окно с таблицей, в которую попадают полученные (и отфильтрованные по id) события. Размеры окна, цвета событий, сам фильтр id событий считываются из .ini файла.  
Ini файл формируется через вспомогательную утилиту Configurator. Configurator с помощью l2encdec раскодирует `SystemMsg-e`, чтобы отобразить пользователю сообщения в читаемом виде. Пользователь может настроить цвета, шрифт, размер окна и сохранить свою собственную палитру.  
Графическое оформление окна чата подготавливает Configurator, с помощью umodel извлекая текстуры игры (тем самым учитываются моды на интерфейс установленные у пользователя).  


## Ограничения
Синхронизация на выгрузке DLL не предусмотрена.  
Нет защиты от повторной инициализации.  
Ограничение на длину передаваемой строки - 512 символов.  
Прозрачный фон чата не поддержан.  
Смена шрифта в чате не поддержана.  
Интеграция `SetParent` с процессом Lineage 2 не поддержана.  
Клики по неактивному интерфейсу окна чата не перехватываются (и пролетают в игру. во избежание случайного движения персонажа - сперва кликните правой клавишей в чат, чтобы сделать окно активным на уровне ОС)
